No-Heat Furnace: From LED Code to Part

Part of the Gas Heat Guide

Last updated: 2026-10-16

A furnace that will not make heat is a puzzle with a built-in clue. The control board watches every step of the start-up and blinks a code when one step fails. The skill is turning that blink into a short list of suspects, then proving which one with a meter, instead of swapping parts.

Start with the code, before you open anything

On most boards a light blinks a pattern that tells you what the board last saw go wrong. One manufacturer guide explains a two-digit pattern: short flashes give the first digit and long flashes the second. Others use two lights, or a steady/flashing combination. The meanings are not universal, so the chart on the furnace door or in the manual for that exact model always wins. The codes in this lesson are fictional examples for teaching, not any maker's list.

Read the code first. HVAC School points out that opening the blower door usually trips the door switch and cuts power, which can clear what the board was showing. Some boards store several past codes, and that history can reveal a pattern, such as a problem that only shows up on a cold start.

Step 1: confirm the basics

Before chasing a code, rule out the simple things. The manufacturer guide's own flow starts with power: line voltage at the furnace, 24 volts at the transformer secondary, a good fuse, a switch left on, and a blower door switch that is actually closed. A board with no light at all is a power question, not a code question.

Step 2: map the code to the sequence

Every fault lines up with a step in the gas furnace sequence of operation. That sequence is: call for heat, the board confirms the limit and rollout switches are closed and that the pressure switch is open, the inducer starts, the pressure switch closes, the igniter warms, gas opens, flame is proven, then the blower starts after a short delay. Use this made-up chart as a pattern:

  • Fictional code 2-1, inducer never proves draft. Suspects: the inducer, tubing, venting, the pressure switch. See Pressure Switch and Inducer Diagnosis.
  • Fictional code 3-2, limit circuit open. Suspects: airflow first. See High-Limit Trips and Airflow.
  • Fictional code 4-1, ignition failed after several tries. Suspects: igniter, gas supply, flame sensor. See igniter care and flame sensor lessons.
  • Fictional code 5-1, flame seen when it should not be. Treat as a gas valve or wiring concern and stop; this is a safety fault.

Step 3: prove it with a meter

A code points at a circuit, not necessarily at a part. HVAC School stresses verifying the board's diagnosis with your own readings. The guide examples show the kind of numbers you compare against the manufacturer: igniter resistance in a stated range, flame signal in microamps, gas supply pressure in inches of water column. Those numbers are model-specific. As one control's example, a White-Rodgers installation sheet lists a minimum flame current of 1 microamp; yours may differ. Use yours.

Also note the retry and lockout behavior. One source describes the board purging and retrying up to three times before locking out; another model's guide describes a lockout that resets by itself after hours. A lockout means the board is protecting you. Cycling power to clear it is fine to restart the diagnosis, but a repeat lockout is information, not a nuisance.

Safety rules that never change

  • Lock out and tag the disconnect before touching wiring or components, and test for absence of voltage.
  • Never jumper a pressure switch, limit, rollout switch or door switch to make a furnace run. One manufacturer guide mentions taping the blower door switch for a test and says to remove the tape before leaving, which is a reminder that any bypass is temporary and your responsibility.
  • A cracked heat exchanger or vent problem can put carbon monoxide in the home. See Combustion and CO Safety Basics.
  • After any repair, run a full heating cycle and confirm normal operation.

Field card: No-Heat Furnace: From LED Code to Part

From code to part, one step at a time.

  • Read the code before opening the door; the door switch can erase it.
  • Check power, fuses and the door switch before chasing a code.
  • Match the code to a step in the start-up sequence to narrow the suspects.
  • Prove the part with a meter reading against the maker's number.
  • Never jump a safety switch; a repeat lockout is a clue, not an obstacle.
