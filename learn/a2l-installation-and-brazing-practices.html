A2L Installation and Brazing Practices

Last updated: 2026-10-16

Part of the A2L Refrigerants Guide

Installing an A2L system is mostly familiar work. A few habits matter more than before because the refrigerant is mildly flammable.

Start with the paperwork

Read the installation instructions for the exact model before you start. They state the allowed line lengths, any room-size rules, required sensors, and special steps. Then check the code adopted where you work. This is the order of authority: manufacturer instructions and the local rules decide, and a general lesson like this one does not.

Tools and equipment

  • Use a recovery machine and a vacuum pump rated for A2L refrigerants (AHRI's best-practices sheet says to use recovery tools rated for A2L and to recover into a DOT-approved cylinder).
  • Use gauges, hoses and a leak detector suitable for the refrigerant and the way its maker describes.
  • Hand tools like flare blocks, wrenches and torque wrenches for flared connections are much the same as before, as an HVAC School episode on A2L installs points out.
  • Cylinders are stored and moved upright and secured so they cannot be banged or knocked over. See Refrigerant Cylinders and Labels.

Flares, brazing and cutting

Many mini-splits join their lines with flared fittings, so some jobs involve little or no brazing. Where brazing is needed, treat it as hot work around a flammable material. Make sure the lines you are cutting into are free of refrigerant, work in a ventilated area, and keep ignition sources and flame away from any place refrigerant could be present. If a pipe may still hold refrigerant, use a copper tubing cutter, not a torch.

Nitrogen

Nitrogen protects the inside of the tubing from oxide scale while brazing. The practice described in HVAC School's episode is a higher-flow purge to clear air, followed by a very low continuing flow, quoted there as about 2 to 5 standard cubic feet per hour. Other sources fall in a similar band (a brazing-supplier page suggests starting near 2 to 3 CFH, and some regulator makers list 3 to 6), so roughly 2 to 6 SCFH is a fair reading of what sources suggest. No standard sets one number. Treat it as an example, and use a regulator and the flow your own procedure and the manufacturer call for. Never use an unregulated cylinder.

Evacuation, leak checks and charging

  • Pressure-test with nitrogen and check for leaks before any refrigerant goes in. See Leaks and Leak Repair Basics.
  • Pull a deep, verified vacuum with a gauge made for it.
  • Charge by the manufacturer's method and record the amount.
  • Verify any leak detection and mitigation features work after install, using the maker's test.
  • Never bypass a sensor or safety.

Ventilation and ignition sources

Work in a ventilated space. Keep sparks, open flame and unnecessary electrical tools away when refrigerant could be released. If you have to recover or release refrigerant, follow your training and the rules for it. More in A2L Service Safety and Tools. The rule that overrides everything on this page: the installation and service instructions for the specific unit in front of you, and the rules where you work, always govern.

Field card: A2L Installation and Brazing Practices

Same trade, a few more careful habits.

  • Read the model's instructions and local code first.
  • Use A2L-rated recovery and vacuum equipment.
  • Keep ignition sources away from any place with refrigerant.
  • Use regulated nitrogen; follow the maker's flow guidance.
  • Verify safety features after install.
